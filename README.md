Sitio web dedicado a la venta del servicio de desarrollo web por parte del desarrollador de este sitio. La página presenta proyectos realizados, los servicios ofrecidos y una forma de contacto para conversar sobre nuevas propuestas.

## Contenido de la página web

- **Inicio:** Presentación y acceso a las secciones principales. proyecto.
- **Servicios:** Desarrollo de sitios web y sistemas de gestión.
- **Proceso de trabajo:** Etapas desde la consulta inicial hasta la entrega.
- **Contacto:** Enlace directo a WhatsApp para iniciar una conversación.
- **Sobre mí:** Perfil y enfoque profesional.
- **Proyectos:** Muestra proyectos destacados por parte del desarrollador, ampliando información por cada uno de los proyectos.

## Estructura del proyecto

El proyecto presenta ficheros y directorios organizados de la siguiente manera:

- **index.html**: Página principal del proyecto
- **src/**: Código fuente del proyecto
- **src/assets/**: Imágenes y otros recursos del proyecto
- **src/styles/**: Estilos del proyecto. Usa archivos CSS con metodología BEM aplicada.
- **package.json**: Configuración y dependencias del proyecto.
- **demos/**: Páginas de demostración.

## Tecnologías

- HTML
- CSS
- TypeScript
- Vite

## Requisitos

- Node.js y npm.

## Uso local

Instalá las dependencias:

```bash
npm install
```

Iniciá el servidor de desarrollo:

```bash
npm run dev
```

Vite mostrará en la terminal la dirección local para abrir el sitio en el navegador.

## Compilación

Para generar la versión de producción:

```bash
npm run build
```

Los archivos generados quedan en `dist/`. Para previsualizar esa versión localmente:

```bash
npm run preview
```
